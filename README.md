# Sistema de Estacionamiento

## Tecnologías

* Java
* MySQL
* NetBeans

## Estructura del proyecto

* modelo → entidades
* dao → acceso a datos
* servicio → lógica de negocio
* controlador → conexión con vista
* vista → interfaz gráfica
* util → conexión y utilidades

## Ramas

* main → versión estable
* logica 
* datos
* interfaz
